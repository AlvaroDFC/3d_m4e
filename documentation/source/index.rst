M4E 3D Documentation
====================

This documentation is for the three-dimensional M4E package in the
`3D repository <https://github.com/AlvaroDFC/3d_m4e>`_. It is written as a
standalone guide; knowledge of the planar 2D package is not required.

The 2D project is a useful reference for shared ideas and its established
examples. See the `2D repository
<https://github.com/Project-SEA-Stack/Python_Multibody_for_Everybody>`_.
The 3D guide calls out differences where they matter, but all instructions here
are for the 3D package.
